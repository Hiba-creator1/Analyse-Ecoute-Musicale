# Analyse-Ecoute-Musicale
Analyse d'Écoute Musicale
# Description
Ce projet Python analyse un jeu de données d'écoutes musicales pour en extraire des tendances et des statistiques clés. Il permet de visualiser les habitudes d'écoute à travers différents graphiques générés automatiquement.
# Technologies Utilisées
Langage : Python
Bibliothèques : Pandas (manipulation de données), Matplotlib/Seaborn (visualisation)
Gestion de version : Git & GitHub
# Analyses Réalisées
Le script génère plusieurs graphiques, notamment :
  -La répartition des genres musicaux les plus écoutés.
  -L'analyse du temps d'écoute par plateforme.
  -Les pics d'activité (heures et jours de la semaine).
#  Comment lancer le projet
 1. Clonez le dépôt :
   git clone https://github.com/Hiba-creator1/Analyse-Ecoute-Musicale.git

 3. Installez les dépendances :
   pip install pandas matplotlib seaborn

 5. Lancez le script :
   python "mini projet.py"
